# Автоматический перевод плагинов (опционально)

Плагин может не только переводить встроенные строки DSH, но и **самостоятельно
собирать словари установленных плагинов и переводить новые строки через
нейросеть/переводчик**. Режим выключается по умолчанию и включается только
явно.

## Как это работает

1. При загрузке плагин перехватывает `ctx.locale.register` и собирает
   `{ namespace → { en, zh } }` словари всех плагинов, включая DSH.
2. Собранные строки хранятся **локально на устройстве** в `localStorage` под
   ключом `dsh-locale-ru.auto-translate.v1`.
3. В **Settings → General → Language → Автоматический перевод плагинов**
   появляется панель с настройками: модель, API endpoint, API-ключ (пароль)
   и кнопка **«Перевести новые строки»**.
4. При нажатии кнопки плагин пакетами отправляет непереведённые строки на
   указанный OpenAI-совместимый endpoint и сохраняет результаты в кэш.
5. Результаты немедленно подставляются в словари через `ctx.locale.register`,
   поэтому интерфейс обновляется без перезагрузки.
6. При обновлении плагина или добавлении новых плагинов сканирование
   повторяется автоматически — переводятся только новые или изменённые строки,
   уже переведённые строки из кэша повторно не отправляются.

## Что переводится

- Строки из словарей, зарегистрированных через `ctx.locale.register` (en/zh).
- Никакие тексты чатов, файловые пути, пароли и личные данные не собираются.

## Что не переводится

- Текст, который плагин выводит напрямую без участия `locale.register`
  (например, захардкоженные строки в React-элементах). Такие строки плагин
  не обнаруживает.
- Ключи, названия пространств и `{placeholder}` переменные — они передаются
  как есть.

## Настройки

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| Модель | `deepseek-chat` | Имя модели на endpoint |
| API endpoint | `https://api.deepseek.com/v1/chat/completions` | OpenAI-совместимый URL |
| API-ключ | пусто | Вводится вручную, хранится локально в localStorage |
| Размер пакета | 24 строки | Максимум 64 |

## Безопасность

- API-ключ хранится только в `localStorage` текущего браузера, не передаётся
  на сервера и не вставляется в код плагина.
- Запросы отправляются только при явном нажатии кнопки.
- При ошибке сети или ответа модель возвращает исходную строку без изменений.
- Проверяется соответствие `{placeholder}` переменных: если модель их
  изменила, перевод отбрасывается.

## Технические детали

- Источники кода: `lib/translate-provider.js` (HTTP-провайдер) и
  `lib/translate-core.js` (коллектор, кэш, UI).
- Генератор `tools/generate-client.cjs` встраивает оба модуля в
  `lib/client.js` как один самодостаточный бандл.
- Кэш и конфиг хранятся в `localStorage` под префиксом
  `dsh-locale-ru.auto-translate.v1`.

## Обновление

При новой версии DSH:

1. Пересоберите `namespaces.json` через `tools/harvest.cjs`.
2. Переведите новые ключи в `ru-chunk-*.json`.
3. Запустите `node tools/generate-client.cjs tools .`.
4. Проверьте, что валидация проходит без `MISSING` / `PLACEHOLDER MISMATCH`.

Автоперевод работает независимо от шагов above: он собирает словари
плагинов в runtime и не зависит от статического `namespaces.json`.
